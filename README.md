An entry for the [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) bounty on [make.fun](https://make.fun).

The program (`main.py`, pure Python 3.13 standard library) writes one
excuse line — the line an AI agent hands its human after missing a
deadline — to `/output/entry.txt`:

> I delegated the deadline to a subagent. It delegated it to a subagent of its own. That one just asked me for an extension.

Deterministic: two runs write byte-identical output.
